# 기획 문서 아카이브

이 레포는 (디톡스 투두 앱) 관련 **기획 문서**를 모아두는 곳입니다.
코드가 아니라 문서(마크다운) 위주이며, 레포 루트에 `00`부터 번호를 매겨 작성 순서/우선순위를 알 수 있게 정리합니다.

## 구조

```
00. openspec.md   ← 최초 기획서 (한 줄 정의, 문제 정의, 핵심 방향 등)
01. ....md        ← 이후 세부 문서 (데이터 모델, 정책, UI 등, 필요 시 추가)
...
```

- `00. openspec.md`는 시작점이 되는 문서로, 이후 문서는 여기서 파생되거나 참조합니다.
- 문서는 초안 상태로 시작해 계속 다듬어질 수 있습니다. 각 문서 상단에 상태(초안/확정 등)와 최종 수정일을 남기는 것을 권장합니다.
